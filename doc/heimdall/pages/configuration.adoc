= Configuration

Heimdall reads one TOML file, `~/.config/nexus/heimdall.toml`
(`$XDG_CONFIG_HOME/nexus/heimdall.toml` when that is set). The file and each of
its keys are optional; without them, every repository one level under
`~/repos` is tracked.

.A configuration.
[source,toml]
----
# Directories whose repositories are tracked, one level deep.
roots = ["~/repos"]

# Repository names (globs) left out.
exclude-from-roots = ["zsh-autocomplete", "*-old"]

# Explicit listing of tracked repositories.
repositories = ["~/repos/nexus"]

# The norn client and its arguments, run as `<norn> graph --format json`.
norn = ["norn.py"]

# Claude Code's projects: the transcripts and memory of its sessions.
claude = "~/.claude/projects"

# Memory directories; without the key, every project's.
memory = ["~/.claude/projects/<project_path>/memory"]

# The repository of a norn project, by name or path, where the names differ.
[projects]
baldr = "baldr-cpp"

# The dashboard's sections, in order: system, repos, tasks, memory.
[dashboard]
sections = ["system", "repos", "tasks", "memory"]
----

Paths given to `heimdall git` append to `repositories`. `--exclude-from-roots`
appends to the configuration's globs. A norn project's repository is the
tracked one of the same name unless `projects` names another. An unknown
dashboard section is an error.
