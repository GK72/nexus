`heimdall memory` shows Claude's memory: per project, its files, their size,
and in how many of the project's sessions Claude read each. The index,
`MEMORY.md`, is loaded in every session; a file is read only when needed.

.The memory of a project.
[source,text]
----
  Memory                                         24 files · 41.9 KB · ~10k tok
                             index 2.8 KB (~700 tok) loaded every session

  ── ~/.claude/projects/<project_path>/memory ── 24 files · 54 sessions
  FILE                 TYPE         SIZE   ~TOK READ IN  CHANGED     HINT
  baldr-tool.md        project    5.0 KB   1.2k   21/54  2026-11-13  → project doc?
  norn-service.md      reference  2.9 KB    735   13/54  2026-11-09  → doc or skill?
  nexus-context.md     user        978 B    245   12/54  2026-10-28
  cpp-naming.md        feedback    872 B    218    7/54  2026-10-31
----

A session read a file when it opened it with the Read tool, named it in a shell
command in the memory directory, or had it attached when Claude Code recalled
it. Tokens are estimated at four bytes each.

== Promotion

A file read in at least 5 sessions and 15% of them gets a hint where it may
belong instead:

.Hints by type.
[cols="1,1,3"]
|===
| Type | Hint | Why

| `reference` | doc or skill    | Facts about a tool are documentation, steps a skill.
| `project`   | project doc     | The project's book or design notes, reviewed and versioned.
| `feedback`  | `CLAUDE.md`     | A rule every session of the repository follows.
| `user`      | none            | About the author, it stays in memory.
|===

A promoted memory shrinks to a pointer to its new home. Documentation loaded
in every session, such as `CLAUDE.md`, costs its tokens every time; a book or
a skill only when it is read.

The reads of each transcript are kept in
`~/.cache/heimdall/memory-reads.tsv` and scanned again once the transcript
changes.
