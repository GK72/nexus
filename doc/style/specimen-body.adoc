== Custom roles

Accent text works at every level; the legend, the notes and the points need the full level.

Accent text: [.red]#red#, [.orange]#orange#, [.yellow]#yellow#, [.green]#green#, [.teal]#teal#,
[.blue]#blue#, [.purple]#purple#. Links out end with an icon: https://asciidoctor.org[Asciidoctor].

[.legend]
[.blue]#Requests# [.orange]#Retries# [.green]#Successes#

[.note]
A `[.note]` paragraph: small print under a table or figure.

[.unused]
An `[.unused]` paragraph: a feature without a caller yet.

[.points]
Tight:: Blocks sit close; the page holds more.
Even:: One gap everywhere, from one token.
Quiet:: Hue marks roles, it does not decorate.

== Icons

Admonitions and links out use them at the full level; `+i:name[]+` puts one in the text at every
level:
i:note[] note, i:tip[] tip, i:important[] important, i:warning[] warning, i:caution[] caution,
i:external[] external, i:chevron[] chevron, i:copy[] copy, i:swap[] swap, i:unused[] unused.
